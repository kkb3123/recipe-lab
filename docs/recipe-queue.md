# 신규 레시피 누적 대기 목록

## 작업 순서

1. [개발 시작 시점의 기존 레시피 51개](recipe-inventory-51.md)를 요리명·셰프·출처로 대조합니다. 셰프명이나 이름 표기만 달라진 같은 조리법은 중복 제외에 기록합니다. 같은 종류라도 핵심 재료와 조리법이 다른 경우 그 근거를 남깁니다.
2. KBS 편스토랑 공식 레시피 글을 먼저 확인합니다. 이어서 방송사 공식 재료·조리법, 셰프 공식 사이트, 공식 영상이나 설명란, 셰프가 직접 공개한 자료 순으로 찾습니다. 영상 확인이 막히면 공식 텍스트를 우선 조사합니다.
3. 공식 출처와 계량·조리법, 사진 검수를 각각 완료한 뒤 등록합니다. 원문이 생략한 인분, 핵심 재료량, 변형 간 수치 차이는 임의로 보충하지 않습니다. 계량이 없는 조리 보조용 물이나 선택 토핑은 원문 기재 여부를 별도 표시합니다.
4. 자료를 덮어쓰지 않고 같은 행의 출처·검증 근거와 다음 작업을 갱신합니다. 사진 검수 결과는 [사진 대기 목록](recipe-photo-queue.md)에 기록합니다.

상태 순서는 **조사 예정 → 출처 확인 완료 → 계량 및 조리법 검증 완료 → 사진 확보 완료 → 최종 등록 가능**입니다. 조리법보다 사진 검증이 먼저 끝난 경우 사진 열에 먼저 기록합니다. **중복 제외**는 별도 표로 보존합니다.

2026년 11월 26일 기존 대기 후보 8개를 등록해 전체 61개가 됐습니다. 16개가 대기 중입니다. 칼빔면은 공식 재료·조리법 원문을 확보할 때까지 대기하고, 원문을 확인한 오돌제육을 등록했습니다.

2026년 11월 25일 기준 활성 후보 26개를 검토했습니다. 그중 2개를 등록해 전체 53개가 됐으며, 24개는 대기 상태입니다. KBS 원문은 공개 공식 레시피 게시판의 본문으로 확인했고, 후보 탐색에 사용한 방송 소개나 재현 글은 계량·조리법의 근거로 사용하지 않았습니다.
