# 신규 레시피 검토

대상 릴리스는 1.2.0-dev.1입니다. 기존 레시피 51개를 유지했고 이번 릴리스에 신규 등록한 레시피는 0개입니다. 방송 영상, 기존 요리와의 중복, 공식 계량과 조리 과정, 이미지 권한을 따로 확인했습니다.

|---|---|

대체 후보는 긴급제육 119, 오돌제육, 명란버터파스타, 후추치즈파스타, 참간초파스타, 칼빔면, 우유버터 봉골레입니다. 방송 노출만 확인된 후보는 공식 카드나 설명과 사진 권한을 확보할 때까지 등록하지 않습니다. [KBS 파스타 모음](https://www.youtube.com/watch?v=UUOpe_sTKzA) · [명란버터파스타 KBS 소개](https://mylovekbs.kbs.co.kr/index.html?contents_id=70000000398817&section_id=10734&sname=mylovekbs&source=mylovekbs&stype=blog)

새 레시피 검사는 고유 ID와 정규화한 이름, 필수 출처·계량·사진 정보를 검사합니다. 주소 구조 검사로 공식 채널 소유나 공개 접근성을 증명할 수 없어 등록 시 원문을 별도로 대조합니다. 이 환경의 YouTube 직접 HTTP 요청은 프록시에서 차단됐으며 KBS 채널 검색 결과와 공식 KBS 페이지를 검토했습니다.
