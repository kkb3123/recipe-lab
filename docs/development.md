## 구현된 기능

- 레시피 검색 및 결과 즉시 표시, 요리 카테고리·셰프 필터, 조리 시간·이름 정렬
- 첫 화면 추천 레시피 1~5위, 재료와 사진 출처, 조리 단계와 인분 환산
- 즐겨찾기 저장·백업·복원, 장보기 구매량 올림·필요량 표시·체크·복사
- PC·모바일 화면, PWA 매니페스트와 아이콘
- 레시피 무결성 및 중복 검사, PC·모바일 기능 테스트, 테스트 통과 후 비공개 개발 미리보기 갱신

## 아직 해결하지 못한 문제

- 권한 또는 원 출처 확인이 필요한 사진은 게시 보류 중입니다. 일부 외부 사진은 응답 제한이 발생할 때 요리 이름으로 대체됩니다.
- 추천 목록은 편집 순서이며 이용 통계 집계 기능은 없습니다.
- 실제 기기 PWA 설치와 오프라인 동작은 검증하지 않았습니다.
- 미리보기는 넷리파이 로그인이 필요하고, 인증 토큰이 만료되면 다음 갱신이 중단됩니다.

## 향후 개발 예정 기능

- 공개 출처를 확인한 류수영·방송·셰프 레시피를 10개 단위로 검토·추가
- 사진 권한 확인 및 허용된 이미지 보완
- 실기기 PWA 설치·오프라인 검증
