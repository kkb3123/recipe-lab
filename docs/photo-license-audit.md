## 표시 의무와 적용

- CC0는 저작자 표시 의무가 없습니다. 공개 후보에서는 출처와 저작자를 표기했습니다.
- CC BY는 저작자, 작품·출처, 라이선스 표시가 필요합니다. CC BY-SA는 변경 시 변경 사실과 동일·호환 라이선스 조건도 적용됩니다. 공개 후보는 Commons 썸네일을 외부 링크로 사용하고 화면 잘림 가능성을 명시합니다.
- 공공누리 제1유형은 제공 기관과 원 출처의 표시가 필요합니다. 해당 파일은 근거 확인 전까지 화면에 포함하지 않습니다.
- 카드와 홈에서 보이는 사진에는 푸터의 크레딧 링크를 제공하며, 레시피 상세의 저작자 표시는 해당 사진의 크레딧으로 바로 연결합니다. 크레딧에는 원본 파일 페이지와 라이선스 링크를 제공합니다.
